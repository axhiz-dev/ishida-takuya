# /business リニューアル仕様（2026-10-07）

## 承認デザイン

会話内で承認された4画面のデザインボードを基準とする。深い緑、クリーム色、自然なオフィス写真、明朝体の見出し。旧人物イラスト・困りごと選択・旧価格は使用しない。

## 導線

- 入口のSTAGE SELECT（LEARN / BUILD）から活用例へ移動。同じ4週間プランの開始段階を示す。
- 活用例一覧 → 個別の会話 → 質問への回答 → 下書き。会話と成果物を同じ場面に並べない。
- 自動送りなし。前後移動、一覧に戻る、ヘッダーから支援内容・料金・無料相談へ移動できる。
- PCでは場面ごとの高さを確保する。スマホ・短い画面では自然な縦スクロールを優先する。
- 会話は架空の見本。実AI、ファイルアップロード、外部連携、永続保存は行わない。

## 基本プラン

1名・1業務、4週間、税込55,000円（税別50,000円）。打ち合わせは60分・30分・30分の3回。Slack中心、メールにも対応。火曜・金曜にまとめて回答（祝日は翌営業日）。自動更新なし。

成果物は再利用できるAIへの指示、確認ルール、使い方の手順。対象業務についての質問・指示修正を含み、全社展開・大人数の研修・日常作業代行・別業務追加は含まない。開発と外部サービス連携は別途相談。AI利用料は顧客負担で、必要な有料ツールは申し込み前に説明する。

無料相談20分は支援適合と範囲の確認。詳しい業務整理と設計は申し込み後。開始前に一括払い。精算条件・支払方法は申し込み前に案内する（計算方法は公開前に確定が必要）。共有された業務資料は終了後30日以内に削除。

## 問い合わせ

必要な項目は名前、メール、相談したい仕事、希望する連絡方法、個人情報の取り扱い確認。初回の連絡はメールで行いSlack希望者へ案内する。既存の `src/components/business/tour/config.ts` で公開Formspree IDを設定する。

未設定時は送信ボタンを無効にし準備中の案内と既存ownerメールへのリンクを表示。設定後はサイト内送信に対応。二重送信ガード、honeypot、15秒タイムアウト、エラー時の入力保持、受付済みの可能性を表示。成功はHTTP成功時だけ表示する。

## 公開前に必要な本人確認

- Formspreeの受信先・公開ID、実送信と実受信
- 既存ownerメールをそのまま使うか、Slack案内方法
- 所在地・電話等の運営者情報と公開プロフィール
- 支払方法・キャンセル時の精算方法
- 仮名称での公開可否

これらはPR作成を止める理由にはしない。未設定の値や未確認の実績を作らない。マージ・公開は今回の作業範囲に含めない。
