# AI活用・伴走支援の体験ツアー

`/business` は業務を選ぶ → AIとの会話を体験 → 進め方と費用 → 導入・相談の4ステップです。
商品は、業務の判断ルールをAIの指示文・スキルへ整理し、見本で検証して社内で改善できるようにする伴走支援。ツール実装は別の選択肢です。

## 編集箇所

- `src/components/business/tour/BusinessTour.tsx`：入口、料金、相談、フォーム。
- `SkillDemo.tsx`：共通の会話UI、見本資料、レポート、確認、保存・翌朝の体験。
- `skillScenarios.ts`：3業務の会話全文、手順、次へボタン、料金の定数 `pricing`。
- `skillSamples.ts`：売上の架空明細、商品名対応表、確認判定と計算。
- `skillDemo.module.css`：会話デモのレスポンシブと短いフェード。
- `data.ts`：入口の人物ラベルと説明。人物の位置は継続。
- `config.ts`：Formspreeの公開フォームID（未設定）。

## デモの動作

売上日報・経費確認・問い合わせ対応を、7場面の会話＋翌朝の活用で体験します。
クリックで話題単位に進み、右側の資料・手順・見本が切り替わります。「戻る」と「ここまでの会話を読む」で全文を再確認できます。場面6では3つの確認を終えるまで次へ進めません。

売上日報の会話では、税込・税抜、送料、返品、重複の扱い、商品名の照合、前日・先週同曜日との比較、数字から断定できない理由を書かないことまで伝えます。元の詳細な会話は要約せず場面に分けて保持しました。

保存は画面内の体験だけです。続く画面で時刻を選び「翌朝を体験する」を押すと、その時刻の下書き通知の見本を表示します。料金に進んで戻っても場面と確認状態を保持し、「最初から見る」でリセットします。再読み込みでは初期状態です。

実際のAI API呼び出し、ファイル解析・アップロード、スキルの永続保存、定期実行、メールやチャットへの送信、ファイルダウンロードはありません。画面には見本であることを表示します。`prefers-reduced-motion` ではフェードをなくし、翌朝演出の待ち時間を0にします。

## 売上の見本データ

送料を除き、税込明細を税抜へ換算。返品は負の金額で扱います。商品は対応表で照合。同じ元ファイル・注文番号・商品・金額が複数ある場合は、両方とも未確認として保留します。未登録商品も保留。特定の人物や顧客名では分岐しません。

確認済みの明細合計は11,000円（マグ9,000円、皿2,000円）。前日10,000円、先週同曜日8,800円との比較は同じ条件の架空実績です。表・商品別円グラフ・合計・比較率は同じ計算結果から表示します。重複候補1組（2行）と未登録商品1行は、合計の対象外であることを明記します。

経費・問い合わせの出力は、会話を説明するために用意した固定の見本です。読み取り・分類が実行されたような待ち時間や処理中表示は使いません。

旧 `Demos.tsx` と `invoicePdf.ts` は既存機能として残しますが、新ツアーから呼び出しません。

## 料金・相談

`pricing` は伴走月3万円〜、実装10万円〜（税別）。伴走は3か月から、社内担当者1名。90分の業務診断の料金は `null` で問い合わせ表示です。外部サービスは顧客契約、利用料別途。

相談は「診断について相談する」と「まずは質問する」。選んだシナリオ名と種別をフォームへ渡します。フォームID未設定のため、送信は無効です。経歴・実績は追加していません。

## フォーム接続（公開前）

所有者のFormspreeアカウントで受信先を確認し、公開フォームIDを `config.ts` に設定してください。再ビルド後、実送信・受信と失敗時の動作を別途確認します。秘密鍵やGmailパスワードは不要です。

入力検証、honeypot、二重送信防止、15秒タイムアウト、失敗時の入力保持は既存処理を継続します。
