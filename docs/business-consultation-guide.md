# 事例から無料相談への動線

## 構成

- 例1・例2の最後に、丸いアイコン付きの「石田ってどんな人？」への小さな入口と、「相談」「支援内容・費用」「もうひとつの事例」の選択肢を表示する。大きな支援説明ボックスは置かない。
- 案内は共通のネイティブdialogに集約。`#pricing` / `#process` / `#faq` / `#about` / `#contact` で直接開ける。
- 案内の項目切り替えは同じ履歴エントリーを更新し、閉じる／Escape／ブラウザーの戻るで背景へ復帰する。事例とフォームをマウントしたまま保持し、案内を開いている間は事例の入力・回答演出を停止する。
- 料金はプランから直接表示し、抽象的な前置きとタブに重複するリンクを置かない。進め方は左に説明、右にトップと同じタッチの専用漫画を置き、4段階を下向き矢印でつなぐ。
- FAQはdetailsで即時展開。自己紹介はユーザー確定稿の文言を維持し、段落内の折り返しだけ画面幅に合わせる。見出しは淡い背景と枠のバナー。名前の下の肩書きは表示しない。段落内のp要素には余白を足さず、段落のまとまりの間に余白を設ける。パネル上端のタイトル・閉じるボタンを固定し、本文をスクロールする。
- 法定ページのヘッダーも現在のサイトに統一。旧 `#contact` などの存在しないページ内リンクを撤去。事例から法定ページを開く場合は別タブとし、途中の会話を失わないようにする。

## 料金

`chat/supportContent.ts` に集約。伴走は月5万円〜、受託は10万円〜（ともに税別、受託は要見積もり）。過去案の「最低3か月」や固定の打ち合わせ回数は引き継がない。AI・LINE等の外部サービスは別途契約・利用料を確認し、支援開始前に範囲と条件を合意する。

## 問い合わせ

- 初回30分無料 → メールで日程調整 → 支援内容・期間・費用の提案 → 合意後に有料支援。
- 見た事例はあくまで参考情報で、相談する仕事を決めつけない。任意の相談文が空でも、確認画面で見ていない事例を選んだ扱いにしない。
- 公開フォームIDが未設定の場合は `owner.email` 宛てのメール受付を提供する。入力・確認後に件名と本文を付けたメールを開く。サイトから送信したとは表示しない。コピー／手動コピー用の本文も用意する。
- サイト内送信を有効にする場合は、受信先を確認した公開Formspree IDを `NEXT_PUBLIC_FORMSPREE_FORM_ID` に設定して再ビルドする（または `tour/config.ts` に公開IDを指定）。これは公開識別子であり秘密鍵ではない。必ず実受信を確認する。
- ID設定時の通信失敗・タイムアウト・再送・二重送信防止は既存のロックとAbortControllerを継続利用する。

## 顔写真

本人の写真は未提供。丸い枠には現在「石田」と表示する。`public/` に本人の写真を置き、`src/content/profile.ts` の `photo` に `/images/...` のような先頭スラッシュ付きのパスを設定すると、丸い顔写真に切り替わる。GitHub PagesのbasePathは表示側で付与する。架空の顔写真や第三者の顔写真で代用しない。
