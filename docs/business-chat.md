# /business 会話型のご案内

2026-10-10。採用したチャット型デザインを既存Next.jsの `/business` に統合。以前のツアーはこのルートから使用しない。旧実装・旧ドキュメントは履歴として残し、現行画面の仕様はこの文書を優先する。

## 今回の範囲

- 白地の会話画面、小さなオリジナルキャラクター、選択肢のリスト、常設のメニュー。
- 起動時の短い入力中表示。自由入力するAIチャットではなく、用意した体験を選択する。
- 集計：表記の違いへの対処 → 照合結果 → 自分の業務の困りごと → 相談。
- LINEシフト：自動募集 → 希望回収 → 未提出者への個別リマインド → 不足枠の募集 → 返信の反映 → 完成通知。
- FAQ・費用・支援の進め方への寄り道と、元の体験への復帰。状態は同じページのメモリ内だけに保持し、リロードでリセット。
- 相談：業務・困りごとの引き継ぎ、名前・メール・任意の補足、同意、確認、送信処理。FAQを開いても入力保持。
- LINE・AIは実接続せず、架空のデータによるサンプルと明記。
- 未確定の価格・サービス条件を断定しない。古い月額価格をページメタデータから除去。
- キャラクターは採用画像をもとに新規生成した透過PNG。画面からの切り抜きではない。

## 送信受付

既存 `src/components/business/tour/config.ts` の `contactConfig.formId` を再利用する。現在は空のため送信不可。入力・確認はできるが、準備中と明記し成功を偽装しない。

ID設定時にはFormspreeの公開フォームIDのみ設定。秘密鍵をフロントエンドへ置かない。HTTP成功時のみ受付完了、二重送信防止、15秒タイムアウト、失敗時の入力保持、ハニーポットを実装。受信先の承認・実受信は別途必要。

## 実装

- `src/components/business/chat/BusinessChat.tsx`: 会話、画面状態、メニュー、FAQ。
- `content.ts`: 選択肢と文面。ビジネス条件確定後に編集。
- `Artifacts.tsx`: ExcelとLINEのサンプル表示。
- `Consultation.tsx`: 入力・確認・送信。
- `chat.module.css`: ページ内に閉じたスタイル、モバイル、reduced-motion。
- `public/images/business/chat-guide.png`: 生成した案内役。

## 検証

型チェック・lint・静的exportの結果はPRに記録。既存E2Eを現行導線へ更新し、CIで実行する。モック送信テストは架空のフォームIDを設定する隔離コピーを使用し、全Formspreeリクエストをインターセプトする。実メールを送信しない。

ブラウザーQAの実施範囲・未確認事項はルートの `design-qa.md` を参照。デザイン参考画像と実装キャプチャは `docs/design/business-chat/`。

## 公開受付を始める前に

料金・支援範囲・利用量の上限と超過時の扱い、問い合わせ受信先、法定表記の既存プレースホルダーを確定する。実機・未確認ブラウザー・実受信を確認する。今回のPRはUI採用が目的で、これらの決定を含まない。
