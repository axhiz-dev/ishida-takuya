# /business 会話型のご案内

2026-10-10。採用したチャット型デザインを既存Next.jsの `/business` に統合。以前のツアーはこのルートから使用しない。旧実装・旧ドキュメントは履歴として残し、現行画面の仕様はこの文書を優先する。

## 今回の範囲

### 2026-10-12 会話への復帰と終了導線

Excel・シフトの体験終了時は「自分の仕事について相談する」「他の事例も見てみる」の2択。内容を追加説明しない「自分の仕事／自分のお店で考えてみる」と、その後の困りごと選択を削除した。

体験を開始した後は、問い合わせ・FAQ・費用などへ移動しても会話コンポーネントを保持する。離れている間は入力・考え中・Bot回答のタイマーを停止し、選択肢パネルも非表示にする。戻ると入力文字数・回答の表示途中・考え中の残り時間から再開し、完了済みの発言は再演出しない。表示月などの成果物内の選択とmainの読み位置も保持する。最初から見る／他の事例を見るでは体験をリセットする。リロード後はリセットする従来の仕様を維持する。

`ConversationActiveContext` で会話の表示中／非表示を伝え、`ChatTurn` と `StreamResponse` が進行を止める。`Choices` は非表示の体験からポータルを出さない。`navigate` が移動前の読み位置を保存し、復帰時に下部パネルの高さが戻った後も読み位置を復元する。

`business-return.spec.ts` で390/1440pxの履歴・読み位置・対象月の保持、通常アニメーションの入力中／考え中／回答中の中断と復帰を検証する。互換性テストにも含める。

### 2026-10-12 月次レポートの追加

集計体験は、照合 → Gmail下書き → サンプル2で月次レポート確認 → finance-checker作成 → 相談の順に進む。月次レポートをスキルの標準成果物に含める。以前の小さなサンプル1はそのまま残す。

サンプル2はAIが動作確認用に生成したという設定の架空データ。サンプル1の実績の拡張ではないことを明記する。2026年4〜9月、8社、売上48件・入金47件と確認済み表記・担当者を含む。9月の売上は5,360,000円、照合済み入金4,300,000円、未入金1,060,000円。期限到来分は田中工業180,000円とさくら企画530,000円、期限前はみなと設備350,000円。照合できない「アオバ」の150,000円は別枠で保留。

対象月切り替え、半年の売上推移、取引先別売上、前月比、対応事項を表示。金額は税込、入金は対象月末までで対象月売上に照合できた分のみ。過去月の未入金を含む全社売掛残高ではない。比較データのない4月は前月比を出さない。推移・前月比較には過去のExcelも必要と案内する。

`public/samples/monthly-report.json` がExcelと画面プレビュー・集計の共通データ。`monthly-report.xlsx` は同じ生成スクリプトから書き出し、ダウンロード可能。3シートの画面プレビューを提供する。生成元は `scripts/build-monthly-report-sample.mjs`。Codex primary runtimeの `@oai/artifact-tool` を使い、依存リンクを置いた一時ディレクトリにスクリプトをコピーして、出力先のsamplesディレクトリを第1引数、任意のレンダリング先を第2引数に渡す。アプリビルド時の再生成は不要。

`MonthlyReportArtifact.tsx` は表示、`monthlyReport.ts` は照合・月次集計を担当する。サンプル2の確認済み対応はサンプル1で人が確認したものと混同しない。実AI・Gmail・スキル保存は既存どおり接続しない。

- 白地の会話画面、小さなオリジナルキャラクター、選択肢のリスト、常設のメニュー。
- 起動時は「AIって、自分の仕事にも使えるの？」から始まる導入文を、300ms後に35msで1文字ずつ表示する。段落の間は260ms置き、表示領域を先に確保する。選択肢は全文表示完了から1秒後に表示する。表示完了をsessionStorageに記録し、同じタブでの再訪時とreduced-motionでは全文を即時表示する。自由入力するAIチャットではなく、用意した体験を選択する。
- 選択後は相談例・回答をユーザー側でタイプ表示し、短いBotの入力中表示を挟んで応答する。「入力を完了して送信」でユーザー入力だけを省略でき、reduced-motionでは即時表示する。画面を離れたらタイマーを解除する。
- 集計の入口は経理担当者の具体的な月末相談。ユーザー発言に `public/samples/monthly-accounting.xlsx` を添付する。クリックすると画面内のダイアログで売上・入金の2シートを切り替えて確認できる。プレビュー用JSONは添付Excelのセルから抽出し、金額・表記を合わせる。
- 選択肢は下部の浮いたパネルに表示し、表示中は入力欄（メニュー起動欄）を隠す。×またはEscapeで閉じると入力欄に戻り、「選択肢を表示」で再開できる。
- 入力演出は45msに1文字。送信後は「考え中...」を2秒表示し、Botは45msに1文字ずつ順番に出力する。選択肢は表・説明を含む応答全体の表示完了から1秒後に表示する。省略ボタンやreduced-motionの場合も1秒待つ。Bot出力中はカーソルを表示する。「回答をすべて表示」とreduced-motionで回答の演出を省略可能。
- 集計はコードのないExcelの表記揺れをAIが提案し、同一企業か人が確認する。差額30,000円を検出した後、ユーザーが社内担当者と宛先を伝えてGmail下書きを依頼する。本文を表示し、未送信であることと架空の連携演出であることを明記する。続いてユーザーが毎月使える**スキル**を依頼し、`finance-checker` の照合ルール・確認済み表記・担当者・実行内容・次回の呼び出し方を表示する。作成後は相談・自分の業務で考える・他事例の選択肢へ進む。前の段階へ戻るリンクは置かず、ブランド名から最初の画面へ戻る。
- 集計の会話履歴は同じ体験内で残す。Botの説明・表・質問を1発言にまとめ、発言ごとのアイコンは1つにする。
- ユーザー発言とBot応答の間は52px、次の発言との間は56px空ける。680px以下ではそれぞれ36px・40pxとし、画面の高さによる圧縮はしない。
- Bot画像は静的インポートし、Next.jsが生成するハッシュ付きURLを使う。会話内では遅延読み込みせず表示する。その他の公開ファイルURLは `BASE_PATH` を明示する。`next.config.ts` の `env` で公開パスのみをクライアントにも渡す。
- 集計：コードなしのExcel → 同一企業の確認 → 差額検出 → 社内担当者へのGmail下書き → finance-checkerスキル作成 → 相談。
- LINEシフト：自動募集 → 希望回収 → 未提出者への個別リマインド → 不足枠の募集 → 返信の反映 → 完成通知。
- FAQ・費用・支援の進め方への寄り道と、元の体験への復帰。状態は同じページのメモリ内だけに保持し、リロードでリセット。
- 相談：業務・困りごとの引き継ぎ、名前・メール・任意の補足、同意、確認、送信処理。FAQを開いても入力保持。
- LINE・AI・Gmail・スキル保存は実接続せず、架空のデータによるサンプルと明記。月末の定期実行は行わず、今月のExcelとスキル名を渡して再利用する体験。
- 未確定の価格・サービス条件を断定しない。古い月額価格をページメタデータから除去。
- キャラクターは採用画像をもとに新規生成した透過PNG。画面からの切り抜きではない。

## 送信受付

既存 `src/components/business/tour/config.ts` の `contactConfig.formId` を再利用する。現在は空のため送信不可。入力・確認はできるが、準備中と明記し成功を偽装しない。

ID設定時にはFormspreeの公開フォームIDのみ設定。秘密鍵をフロントエンドへ置かない。HTTP成功時のみ受付完了、二重送信防止、15秒タイムアウト、失敗時の入力保持、ハニーポットを実装。受信先の承認・実受信は別途必要。
