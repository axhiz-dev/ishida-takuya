# LINEのシフト調整をAIと仕組みにする体験

例2は、完成したbotの機能を順に見る体験から、店長とAIの相談で運用ルールを決める体験へ変更。

1. 困りごとを伝え、募集日・締切・確定する人を質問される。
2. 毎月20日募集・25日締切、店長が最終承認することを伝える。
3. 自由な返信とLASTの扱いを指示し、曖昧な開始時間だけ聞き返すLINE見本で確かめる。
4. 催促を未回答者へ24日に1回と決め、締切後の返信を店長に知らせる。
5. 必要人数と、追加募集の承認範囲を質問される。
6. 土日の夜は3人・責任者1人、追加募集の対象と文面は店長承認後に送ると伝える。
7. 指示文と架空スタッフ5人の固定の見本を確認し、試して直す進め方を知る。

`src/components/business/chat/content.ts` に会話・次の質問・見本の種類を定義。`BusinessChat.tsx` は例1と同じ `ChatTurn` と `Choices` を使い、前の会話も残す。`Artifacts.tsx` はLINEの動作見本と最終指示文を表示する。

LINE見本の指定文言：

> スタッフ：火曜は夕方から入れます
>
> bot：火曜日は何時から勤務できますか？
>
> スタッフ：17時からです
>
> bot：火曜日17時からLASTで登録しました！

実際のAI・LINE連携、保存・送信・シフト計算は行わない選択式デモ。実装・接続の前に指示を整理して見本で確かめる伴走支援として見せる。
